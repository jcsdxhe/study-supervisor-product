# 长期路线图

路线图按可验收版本管理，P0/P1/P2 表示版本内优先级而非独立产品线。历史正式发行使用 `1.x` 版本号；以下 `v0.x` 是产品能力阶段映射，用于长期规划，不回改既有发行号。

## 能力版本映射

### v0.1：学习管理基础（对应正式发行 1.0.0）

- [x] 周计划、每日任务、计时、成绩、复盘、数据导入导出和证据附件。

### v0.2：监督与本地题目白板（对应正式发行 1.1.0–1.2.1）

- [x] 显式授权的专注签到、休息提醒与隐私边界说明。
- [x] 图片/PDF 多页白板、批注、撤销重做、PNG 导出与可选 Kimi 辅导。

### v0.3：语音课堂与随讲随画（对应正式发行 1.3.0–1.4.0）

- [x] 浏览器语音识别与朗读、打断、回声抑制、结构化题图标记和自动续页板书。

### v0.3.1：模块化每日学习汇报（未发布）

- [x] 模型无关的可插拔日报分析器接口；首版不接入 AI。
- [x] 任务、成绩和白板页面的右键编辑/删除入口，以及本机个人资料管理。

- [ ] 在用户明确配置后提供经过协议校验的可选分析器适配器。

### v0.4：数学可视化与课堂可靠性（计划，P0）

该基线不包含通用几何/三维绘图、账号、支付、云同步、自动更新或原生模型实时音频。

## P0：数学可视化与课堂可靠性

- [x] 建立受限数学表达式 AST 与结构校验，支持二维显函数、多曲线、定义域和值域。
- [x] 绘制坐标轴、刻度、网格、曲线和区域填充；自动极值/渐近线标注仍留待后续。
- [x] 新增受控 `plot` 课堂事件，函数图写入本机白板并保留在课堂页面栏。
- [x] 新增直线、抛体、斜面及一维多物体碰撞四类受控 `motion` 动画，不执行模型代码。
- [x] 为课堂 `motion` 页面增加播放、暂停、进度拖动和重新播放，并保存经校验的动画参数用于回看。
- [ ] 支持参数方程；隐函数和三维图放在后续版本。
- [x] 为非法表达式、超大范围、响应截断、协议失效、漏画图和课堂请求无响应增加拒绝与可见重试。
- [x] 优化首次读图的尺寸控制、局部选区和明确进度；不得伪造 1–2 秒承诺。
- [x] 取消低信心/高图像依赖的供应商跳转门控；Kimi 必须继续尝试、标明不确定内容且不得补写题干。
- [ ] 扩充语音/批注/板书协议的端到端 mock 测试；真实 API 冒烟只在必要时运行并记录余额消耗。

P0 完成门槛：不执行表达式或模型代码；所有 `plot` 输入经结构、白名单与计算预算校验；绘图可撤销、重做和导出；非法输入、奇点、超时和协议错误具有确定性回退；自动化检查与 headed Edge/Chromium 视觉验收通过。真实 Kimi 冒烟测试仅在 mock 无法覆盖时运行并记录余额消耗。

## P1：产品化

- [ ] 完成首次启动向导、API Provider 配置检查和可恢复的错误提示。
- [ ] 数据备份/恢复、版本迁移和损坏数据恢复测试。
- [ ] 将课堂档案与大体积录屏纳入可选、分卷的备份恢复，并提供存储配额管理。
- [ ] Windows 安装器或签名的便携包；自动更新必须是用户可控且可关闭的。
- [ ] 完成全量无障碍和键盘验收；手机 390px、平板 820px 和电脑 1440px 的主要导航/课堂流程已有 Edge 回归，仍需补 1366×768 / 2K / 4K 与真实 iOS/Android 设备矩阵。
- [ ] 形成稳定的发布流水线、版本策略、校验和与回滚说明。

P1 完成门槛：从干净工作树构建的发行包不含密钥和用户数据；无密钥基础流程、备份恢复、迁移失败回退、键盘操作和目标分辨率均有可重复验收证据。

## P2：商业准备

- [ ] 明确授权方式、定价、退款、升级、支持期限和客户服务流程。
- [ ] 由专业人士审核许可、隐私政策、消费者条款和第三方模型服务条款。
- [ ] 建立依赖许可证清单与 SBOM；增加依赖漏洞检查。
- [ ] 如需账号、支付或云同步，必须单独设计安全与隐私架构，不能从当前本地版暗中扩张。
- [ ] 建立匿名崩溃报告时也必须默认关闭并取得单独同意；不得采集题目、声音或学习内容。

P2 中涉及定位、收费、授权、账号/云边界或核心隐私承诺的决策，实施前必须由项目所有者确认；技术实现不得先行暗中扩大数据收集范围。

## 暂不承诺

- ChatGPT/Kimi 原生双向低延迟语音；
- 自动且准确地识别手机使用、走神或学习质量；
- AI 答案正确率、提分效果或考试结果；
- 双人同步共画和远程真人监控。

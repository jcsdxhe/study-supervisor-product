# 售卖前说明

当前仓库已经具备可演示、可本机分发的产品基础，但“能打包”不等于“已经完成商业合规”。

## 当前交付模型

- 用户购买本地应用并自行提供模型 API Key（BYOK）。
- 学习计划和白板数据默认只留在用户浏览器。
- 只有用户主动请求 AI 时，题图/问题才经本机代理发往用户选择的模型服务商。
- 发行包不内置共享密钥，不代用户承担模型费用。

## 售卖页面必须讲清

- 需要 Windows、Node.js、Edge/Chrome；AI 功能另需兼容的 Kimi 账户、余额和 Key。
- AI 可能出错，只是学习辅助，不保证答案、分数或考试结果。
- 语音由浏览器识别和朗读，音色/可用性因系统而异。
- 摄像头监督依赖页面和本机信号，不是准确的人体行为识别。
- 用户主动发送给 Kimi 的题目受 Kimi 服务条款与隐私政策约束。

## 尚未实现的商业系统

账号、支付、订单、授权码、设备解绑、自动更新、云备份、客服后台均不在 1.4.0 中。决定加入任何一项前，应先形成单独需求、威胁模型和隐私方案。

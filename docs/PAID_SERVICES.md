# 可能产生费用的能力清单

基础学习管理、题目白板、课堂档案、浏览器语音识别/朗读和本地录屏可以在本机免费运行。以下项目只有在选择对应商业化能力时才会产生第三方费用；价格会变化，实施前以供应商当日条款为准。

| 能力 | 何时需要付费 | 当前免费替代 |
| --- | --- | --- |
| Kimi 或其他大模型 API | AI 读题、持续讲解、复盘、作业生成产生按量调用费用 | 不配置密钥时，计划、任务、成绩、资料和白板继续可用 |
| 常驻云代理 | 希望公网课堂无免费实例休眠、低冷启动并提高可用性时 | Render 免费实例可用，但休眠后首次请求可能明显延迟；本机运行无该问题 |
| 高准确率云端语音识别与自然语音 | 需要跨设备一致的数学/物理词汇识别、低延迟流式 ASR、专业音色时 | 浏览器 SpeechRecognition 与 speechSynthesis，效果受浏览器和系统音色限制 |
| OCR、长文档解析或自建 GPU | 需要复杂扫描 PDF、公式 OCR、批量教材索引和更稳定版面理解时 | 当前最多 10 页、本机 PDF 渲染、用户选页与人工校对 |
| AI 教学图片、视频或高复杂度三维生成 | 需要每节课实时生成高质量插图、视频、复杂 3D 网格或云端渲染时，通常会产生模型或 GPU 按量费用 | 当前函数图、板书和受控多物体物理动画在浏览器本机确定性渲染；后续可先加入免费参数化 3D 基元 |
| 云账户、同步、数据库和对象存储 | 需要多设备同步、团队班级、云端录像、自动备份时 | localStorage/IndexedDB 和本地导出；当前课堂媒体不上传 |
| 应用商店与签名 | 发布 iOS、Android、华为应用市场或带信誉签名的桌面安装包时 | PWA 可直接从支持的浏览器安装；具体平台开发者账号、证书和审核可能收费 |
| 自定义域名和商业邮件 | 使用品牌域名、事务邮件、找回账号和通知时 | Render 提供的平台子域名；本地版无需域名 |
| OpenMAIC 具体版本授权核对 | 选择旧版 AGPL 源码并希望采用其他分发许可时，需另核对可用授权与费用 | 当前仅参考设计；2026-10-23 核对的上游 `ee300e00` 根许可证为 MIT，具体版本与依赖边界见 `THIRD_PARTY_NOTICES.md` |
| 法律、隐私和许可证审查 | 正式收费、处理未成年人数据、跨境或进入应用商店前 | 开发期模板和技术边界说明不能替代专业法律意见 |
| 监控、客服和分析 | 商业运营需要可用性告警、错误追踪、客服工单和隐私合规分析时 | 本机日志与用户主动反馈；默认不收集学习内容和音频 |

付费能力不得暗中扩大数据收集范围。任何云同步、云录屏、账户系统或第三方分析都必须单独设计授权、删除、导出和恢复流程，并在启用前取得用户明确同意。

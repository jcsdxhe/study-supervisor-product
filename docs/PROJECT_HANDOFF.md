# 项目交接总览

## 当前状态

- 产品：**向前 · 学习督导台**
- 当前版本：`1.6.0`
- 形态：Windows 本机 Node 服务 + 浏览器单页应用
- 默认地址：`http://127.0.0.1:4174`
- 默认模型：`kimi-k2.6`，可选 `kimi-k3`
- 基础功能不依赖密钥；AI 题目辅导需要用户自行提供 Kimi API Key。

## 已完成功能

1. 当前基准周的周计划、A/B 优先级、每日执行清单和 23:00 核验模板。
2. 任务证据附件、笔记、本地持久化、数据导入导出。
3. 红/黄/绿周复盘、番茄钟、学习会话、偏差和次日重点。
4. 教资科一/二/三、英语一、数学一、408、六级成绩与错误类别追踪。
5. 每日词汇、听力、写作/翻译维护任务。
6. 隐私优先的专注签到：显式摄像头启动、页面/键鼠信号、休息申报、连续专注提醒、可选 FaceDetector 在座辅助。
7. 本地题目批注板：图片、多页、PDF 本机栅格化、画笔/荧光/形状/文字、撤销重做、PNG 导出、IndexedDB 保存。
8. Kimi 本机代理：密钥只读 `.env`，能力边界自检、K2.6/K3、会话限额、结构化建议批注和用户确认。
9. 实时语音课堂：浏览器中文语音识别、流式回答、按句朗读、打断、回声抑制、键盘备用输入。
10. 随讲随画：第一次读图建立题目区域坐标；后续以结构化事件输出口语、题图荧光/圈选/箭头和板书；空间不足自动新建横向板书页。
11. 课堂可靠性：模型不再控制板书坐标，本机按行高确定性排版并自动续页；麦克风默认屏蔽，打断与提问分离，识别文字默认确认后提交。
12. 可安装 Web App：提供 PWA 清单、响应式手机布局和离线基础壳；AI API 明确不缓存，本机 Node 仍只监听 `127.0.0.1`。
13. 安全云代理：已实现强制秘密门槛、口令登录、签名 Cookie、同源 POST、安全响应头、容器和 Render Blueprint；2026-07-28 已部署至 Render Free Web Service：`https://study-supervisor-product.onrender.com`。
14. 课堂中心与资料导师：课堂模式、统计、搜索和时间轴集中到独立页面；PDF/图片/文字资料进入独立本机资料库，PDF 最多 10 页，可送入批注板后开始课堂。
15. 录屏控制：保留显式屏幕共享，新增暂停/继续；课堂页面、师生文字和录屏状态形成轻量事件时间轴，媒体本体仍只存本机。
16. 跨设备外壳：手机抽屉和底部快捷栏、平板紧凑侧栏、电脑可收起侧栏；课堂手机端在讲义/对话间切换，历史课堂进入完整子页面。
17. 一键课堂工作室：可配置主题、目标、时长、难度、场景和教学角色；课堂生成页与个人题目在白板目录中分开。
18. PDF 与语音确认：PDF 通过缩略图选择最多 10 页，低置信度语音提供候选文本并允许编辑后发送。

## 重要边界

- 当前不是 Kimi 或 ChatGPT 原生双向实时语音。音频输入/输出由浏览器提供。
- 浏览器语音识别可能自行断句或依赖厂商在线服务；应用只保证保留转写并由用户确认，不能保证识别准确率。
- 当前音色自然度取决于 Windows/浏览器已安装语音；优先 Natural/Online，但不能承诺像 ChatGPT Voice。
- 首次读图明显慢于后续文本轮次。
- 当前随讲批注支持文本、框、圈、荧光和箭头，并已实现白名单二维函数曲线与直线/抛体/斜面动画；参数方程、隐函数、三维图和通用几何作图尚未实现。
- 应用没有账号、支付、授权码、自动更新、云同步或客服后台。
- PWA 可以安装为浏览器应用，但不是 Apple、华为或 Android 商店的原生签名包；移动商店发布需要独立开发者账户、签名和安全代理设计。
- `TERMS_TEMPLATE.md` 只是模板，正式售卖前需由适用法域的专业人士审核，项目不得声称已经“合规认证”。

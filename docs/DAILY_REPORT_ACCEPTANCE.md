# 每日学习汇报模块验收标准

## 首版范围

- 用户可新增任意名称的学习目标；日报字段和 Markdown 生成不得依赖“教资、英语、数学”等固定科目。
- 每个目标可记录今日任务、未开始/进行中/已完成、0–1440 分钟学习时长和备注。
- 每日复盘包含最大收获、最大失误和明天重点，并按日期恢复本地记录。
- 证据中心统一接收多张图片、视频、PDF 和文字笔记；每项证据保留日期及可选目标关联。
- 一键生成确定性的 Markdown，支持复制、预览和下载 `.md`；附件只列文件名和说明，不嵌入、不上传。
- 基础流程在离线、无账号、无 API Key 时完整可用。
- AI 分析仅定义可插拔 TypeScript 接口与注册表。首版不注册模型、不发送网络请求、不自动分析。

## 数据与恢复

- 日报元数据使用 `forward-daily-report-v1`，结构包含显式版本号 `1`。
- 媒体证据继续使用 `forward-evidence` IndexedDB，数据库升级到版本 `2`，保留旧 `files` 记录并增加日期/目标索引。
- 旧附件缺少新元数据时仍可在证据中心显示为未关联记录。
- 归档目标只从新日报录入区隐藏，不删除历史日报或证据。
- 删除证据必须二次确认；浏览器存储失败应给出可见提示。

## 非目标

- 不进行 OCR、内容识别、质量评分、自动总结或任何模型调用。
- 不做云同步、账号、多设备共享或后台上传。
- Markdown 不打包二进制附件；完整备份/恢复证据属于后续版本。

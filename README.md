# 向前 · 本地学习督导台


一个完全在本机运行、无需账号或 API 密钥的中文学习管理应用。任务、计时、成绩和复盘数据保存在浏览器 localStorage；上传的证据保存在浏览器 IndexedDB。

## 启动

双击 `启动学习督导台.bat`，浏览器会自动打开 `http://127.0.0.1:4174`。保持黑色命令窗口开启；关闭窗口即停止服务。

也可在此目录运行：`npm.cmd start`。检查：`npm.cmd run check`。

## 隐私

摄像头、麦克风、屏幕共享只有在你点击对应按钮后，浏览器才会请求一次授权。页面不录制、不上传、不在后台持续监控。刷新或关闭页面会停止媒体流。建议定期在“数据”按钮中导出备份。

## 本地专注监督

在“专注签到”中点击“开始摄像头监督”后，应用才会请求摄像头权限并开始本轮监督。默认规则：页面离开或无法确认在座超过 10 分钟提醒、键鼠无活动超过 10 分钟发出分心自查、连续专注超过 120 分钟提醒休息。三项阈值均可修改。

- “报告休息”会暂停离开与分心告警；结束休息后重新计算连续专注时间。
- 页面切到后台时摄像头轨道暂停，回到页面后恢复；结束监督会立即关闭摄像头。
- 设置与最近 30 次监督记录只保存在浏览器 localStorage。
- 支持 `FaceDetector` 的浏览器可主动开启实验性“在座辅助”。它只判断画面中是否可能存在人脸，可能误判，不进行身份识别。
- 普通浏览器摄像头无法可靠判断手机使用。应用只根据键鼠活动、页面状态和可选在座信号提醒用户自查，绝不会把无活动宣称为“检测到玩手机”。

## 本地题目批注板

导航栏中的“题目批注板”用于本机即时绘制和导出，不是两人实时同步共画，也没有 AI 或远程用户控制。

- 可导入多张题目图片，或创建多张空白页；支持页面切换、复制、改名与删除。
- 工具包括画笔、荧光笔、直线、箭头、圆形、矩形、文字和批注橡皮，并支持颜色、粗细、撤销与重做。
- 图片和批注保存在浏览器 IndexedDB；当前页可合成为 PNG 下载。
- PDF 通过内置 PDF.js 在浏览器本机按所选页码栅格化，可直接批注、框选、请求讲解并导出 PNG。
- 未单独配置合法 API 时不会上传题目、不会调用 AI，也不会改动批注板。

## 配置 Kimi 题目讲解（可选）

Kimi 集成默认关闭。API 密钥只由本机 Node 服务从 `.env` 读取，不进入网页源码、浏览器 localStorage、请求日志或导出的批注文件。**不要把 API 密钥发送到聊天、截图或他人。**

1. 登录 [Kimi API 开放平台](https://platform.kimi.com/)，在控制台创建 API Key，并确认账户余额与所选模型权限。
2. 在本项目目录复制 `.env.example`，将副本命名为 `.env`。
3. 仅在本机文本编辑器中打开 `.env`，把 `MOONSHOT_API_KEY=sk-your-local-key-here` 的占位内容替换为你的真实密钥。
4. 保存后关闭并重新运行 `启动学习督导台.bat`。
5. 打开“题目批注板”。状态应变为“本机代理已配置”；输入或语音转写问题、选择模型、勾选本次发送确认，然后点击“讲这一题”。

默认模型为 `kimi-k2.6`。可以主动切换至 `kimi-k3`，但应先查看 [Kimi 官方模型与价格](https://platform.kimi.com/docs/models)；模型价格和账户权限可能调整，应用不会猜测或显示未经确认的金额。

### 实时语音课堂

“实时语音课堂”是题目页的默认入口。进入课堂时，应用会把当前题目画布发送给 Kimi 做一次快速、准确的读题准备；准备完成后，后续问题只发送浏览器识别出的最终文字，避免每轮重新上传大图。你可以直接说话，短暂停顿后自动提交；回答收到第一个完整句子就开始由浏览器朗读，不必等全文生成完毕。点击麦克风可以打断当前回答并继续提问，键盘输入始终可作为备用。

- 课堂默认开启“允许老师随讲随画”：老师讲到题干公式或选项时，会在原题图上使用荧光、圈选或箭头；关键公式与推导写入“老师板书”页，单页空间不足会自动新建下一页。随讲标记存于本机 IndexedDB，可撤销、重做和导出。
- 可从系统提供的中文音色中选择声音，并调节 0.85–1.45 倍语速。应用会优先选择名称带 Natural / Online 的中文音色；实际自然度取决于电脑和浏览器已安装的语音，不等同于 ChatGPT 原生语音。
- 第一次进入课堂需要完成一次读图和区域定位，可能明显慢于后续问答；同一课堂的后续问答不会重复上传大图。

- 语音课堂默认用四至八个适合口头表达的句子回应；要求“完整讲解”时会完整分步讲，不受旧快速提示模板限制。
- 每节课堂默认最多 20 轮，可在 `.env` 用 `KIMI_VOICE_TURN_LIMIT` 设置为 3–50。
- 实测清晰数学题在一次读图准备后，后续完整讲解的首句约 1.55 秒可供朗读；这是本机当次测试结果，不是网络服务延迟保证。
- Kimi 当前公开 Chat Completions 接收文本、图片和视频，不接收本应用的原始麦克风音频。中文语音识别和声音输出由浏览器提供，不是 Kimi 原生实时音频流。
- 浏览器语音识别服务可能依照浏览器厂商政策处理麦克风音频；页面只将最终转写文字发给 Kimi。结束课堂、切到后台或关闭页面会停止识别与朗读。
- 为减少扬声器回声误触发，应用在朗读结束后短暂冷却，并忽略紧随其后的最近朗读文本回声。

隐私与消费保护：

- 只有点击“讲这一题”并勾选本次确认后，当前画布 PNG 与问题才会经 `127.0.0.1` 本机代理发送到 Kimi API。
- 默认每个浏览器会话最多请求 5 次，可在 `.env` 通过 `KIMI_SESSION_LIMIT` 调整为 1–20。
- 图片分辨率会影响 Token 消耗；发送前可先裁剪题目范围。
- Kimi 返回的结构化批注建议默认不选中。必须由用户勾选并再次确认，应用才会添加；模型不能直接修改原画布。
- 本次未加入实时音频 API。讲解完成后可以使用浏览器的“本机朗读”，它不代表 Kimi 实时语音或远程控制。

互动辅导默认为“快速引导”：只返回一个下一步、短原因和一个检查问题；需要完整推导时再主动切换“详细讲解”。回答文字会从本机代理流式显示。可以框选题目区域后再问，也可开启“停笔 12 秒后提示”，但停笔功能只在本机显示询问按钮，绝不会自动调用 API。

备用文字模式中的麦克风仍作为浏览器语音转文字入口：点击开始/停止，或按住说话、松开结束；识别语言为中文 `zh-CN`。转写结果会先放入可编辑输入框，只有用户再次点击“讲这一题”时，最终文字才发送给 Kimi。原始麦克风音频不会由本应用发送给 Kimi；切换到后台会停止识别。不支持 Web Speech Recognition 的浏览器会保留完整键盘输入流程。

每次 Kimi 辅导分成两阶段：先用严格 JSON 返回“能力边界自检”和一次性本机凭证，通过能力门后才发起流式讲解，因此被拦截的题目不会提前生成答案。来源清晰度、难度、模型自评信心、图像依赖度和简短理由会直接显示。高信心时正常进入快速辅导；中等信心时先显示风险提示，由用户确认是否继续；低信心、来源不清或高度依赖图像时默认拦截解答，建议转到 ChatGPT 学习模式或上传截图给 GPT 复核。用户可以点击“仍要 Kimi 尝试”覆盖拦截。此分类只是 AI 自我检查，不是正确性保证；系统提示明确要求模型承认不确定、索要更清晰材料，并禁止虚构题干或推导。

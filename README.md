# 向前 · 本地学习督导台


一个面向 Windows 的中文、隐私优先、本地优先学习管理应用。周计划、任务、计时、成绩和复盘等基础功能无需账号、网络或 API 密钥；相关数据保存在浏览器 localStorage，证据附件、题图、PDF 页面和白板批注保存在 IndexedDB。AI 题目辅导是用户主动配置、主动发送的可选增强能力。

## 当前能力

- 本地学习管理：周计划、每日任务、番茄钟、成绩追踪、证据附件和周复盘。
- 专注签到：基于页面、键鼠和可选摄像头在座信号提供提醒，不做身份识别，也不能可靠判断手机使用。
- 题目批注板：多页图片/PDF、画笔与形状、文字、撤销重做、框选提问和 PNG 导出。
- 可选 Kimi 辅导：经本机 Node 代理或口令保护的同源 HTTPS 云代理完成能力自检、流式讲解、结构化建议批注和语音课堂。

当前版本为 `1.4.0`。数学函数曲线、几何图等精确教学可视化仍在规划中；双人同步、云同步、原生模型实时音频和远程监控均未实现。

## 技术栈

| 层次 | 技术与职责 |
|---|---|
| 前端 | 原生 HTML、CSS、JavaScript；Canvas 白板；MediaDevices；Web Speech API |
| 本地存储 | localStorage 保存结构化学习状态，IndexedDB 保存附件、题图、PDF 页面和批注 |
| PDF | `pdfjs-dist` 在浏览器本机按页栅格化 |
| 安全代理 | Node.js HTTP 服务，默认仅监听 `127.0.0.1`；获授权后可作为带认证的同源 HTTPS 容器服务运行 |
| 可选 AI | Kimi Chat Completions，经本机或安全云代理及 SSE/JSONL 流式协议调用 |
| 测试与发行 | Node.js 检查脚本、PowerShell 本地打包与校验和流程 |

## 启动

需要 Windows、Node.js 18 或更高版本、npm，以及最新版 Edge 或 Chrome。双击 `启动学习督导台.bat`，浏览器会自动打开 `http://127.0.0.1:4174`。保持黑色命令窗口开启；关闭窗口即停止服务。

也可在此目录运行：`npm.cmd start`。检查：`npm.cmd run check`。

开发或首次从源码安装时，先运行 `npm.cmd ci`。正式提交或发行还需执行 `npm.cmd run package:local`；完整要求见 `AGENTS.md` 与 `docs/RELEASE_CHECKLIST.md`。

## 隐私

摄像头、麦克风、屏幕共享只有在你点击对应按钮后，浏览器才会请求一次授权。页面不录制、不上传、不在后台持续监控。刷新或关闭页面会停止媒体流。建议定期在“数据”按钮中导出备份。

## 本地专注监督

在“专注签到”中点击“开始摄像头监督”后，应用才会请求摄像头权限并开始本轮监督。默认规则：页面离开或无法确认在座超过 10 分钟提醒、键鼠无活动超过 10 分钟发出分心自查、连续专注超过 120 分钟提醒休息。三项阈值均可修改。

- “报告休息”会暂停离开与分心告警；结束休息后重新计算连续专注时间。
- 页面切到后台时摄像头轨道暂停，回到页面后恢复；结束监督会立即关闭摄像头。
- 设置与最近 30 次监督记录只保存在浏览器 localStorage。
- 支持 `FaceDetector` 的浏览器可主动开启实验性“在座辅助”。它只判断画面中是否可能存在人脸，可能误判，不进行身份识别。
- 普通浏览器摄像头无法可靠判断手机使用。应用只根据键鼠活动、页面状态和可选在座信号提醒用户自查，绝不会把无活动宣称为“检测到玩手机”。

## 本地题目批注板

导航栏中的“题目批注板”用于本机即时绘制和导出，不是两人实时同步共画，也没有 AI 或远程用户控制。

- 可导入多张题目图片，或创建多张空白页；支持页面切换、复制、改名与删除。
- 工具包括画笔、荧光笔、直线、箭头、圆形、矩形、文字和批注橡皮，并支持颜色、粗细、撤销与重做。
- 图片和批注保存在浏览器 IndexedDB；当前页可合成为 PNG 下载。
- PDF 通过内置 PDF.js 在浏览器本机按所选页码栅格化，可直接批注、框选、请求讲解并导出 PNG。
- 未单独配置合法 API 时不会上传题目、不会调用 AI，也不会改动批注板。

## 每日学习汇报

导航栏中的“每日汇报”用于按日期记录学习成果。学习目标由用户动态添加，不限定为教资、英语、数学或任何预设科目。每个目标都可以填写任务、完成情况、学习时长和备注，并补充“最大收获、最大失误、明天重点”。

- 证据中心统一保存图片、视频、PDF 和文字笔记，可关联汇报日期与学习目标；文件仅进入浏览器本机 IndexedDB。
- 日报可一键生成、预览、复制或下载 Markdown。Markdown 只列出证据名称与说明，不嵌入二进制文件。
- 首版不调用 AI。代码提供模型无关的 TypeScript 分析器接口，未来可在用户主动配置和触发后接入不同模型。
- 当前“数据”按钮的 JSON 备份不包含证据中心附件；完整媒体备份与恢复属于后续版本。

## 编辑、删除与个人管理

- 在“今日执行”或“周计划”中右键任务，可修改名称、说明、时间、星期和 A/B 优先级，也可经确认后删除。
- 在“成绩追踪”中右键科目卡片或图表记录，可修改科目、分数、日期和错因，也可经确认后删除。
- 在题目批注板的页面缩略图上右键，可重命名或删除导入题图、课堂截图、老师板书和教学图像；删除会同时移除该页本地批注且不可撤销。
- 点击左上角“向前”品牌区或右上角头像进入个人管理。称呼、目标、目标日期、每日目标时长和个人提醒保存在浏览器本机，不会上传。
- 键盘用户可聚焦任务或成绩记录后按 `Shift+F10` 打开同一操作菜单。

## 配置 Kimi 题目讲解（可选）

Kimi 集成默认关闭。API 密钥只由本机 Node 服务从 `.env` 读取，不进入网页源码、浏览器 localStorage、请求日志或导出的批注文件。**不要把 API 密钥发送到聊天、截图或他人。**

1. 登录 [Kimi API 开放平台](https://platform.kimi.com/)，在控制台创建 API Key，并确认账户余额与所选模型权限。
2. 在本项目目录复制 `.env.example`，将副本命名为 `.env`。
3. 仅在本机文本编辑器中打开 `.env`，把 `MOONSHOT_API_KEY=sk-your-local-key-here` 的占位内容替换为你的真实密钥。
4. 保存后关闭并重新运行 `启动学习督导台.bat`。
5. 打开“题目批注板”。状态应变为“本机代理已配置”；输入或语音转写问题、选择模型、勾选本次发送确认，然后点击“讲这一题”。

默认模型为 `kimi-k2.6`。可以主动切换至 `kimi-k3`，但应先查看 [Kimi 官方模型与价格](https://platform.kimi.com/docs/models)；模型价格和账户权限可能调整，应用不会猜测或显示未经确认的金额。

### 实时语音课堂

“实时语音课堂”是题目页的默认入口。进入课堂时，应用会先把题图压缩为最长边不超过 1800 像素的 JPEG 请求副本，再发送给 Kimi 做一次读题准备；本机原图不会被改写。准备完成后，后续问题只发送确认后的文字，避免每轮重新上传大图。回答收到第一个完整句子就开始由浏览器朗读，不必等全文生成完毕。

- 麦克风默认处于“已屏蔽”状态，老师讲课和等待回答期间都不会启动语音识别，因此环境响动不会打断讲题。需要提问时点击屏蔽按钮或麦克风按钮；“立即打断老师”是独立按钮，不再与麦克风开关混用。
- 浏览器识别到停顿或自行结束识别时，已有文字保留在输入框，默认必须检查后点击“确认发送”。需要原来的免手动体验时，可以主动开启“停顿 2.2 秒后自动发送”；继续说话会重新计时。

- 课堂默认开启“允许老师随讲随画”：老师讲到题干公式或选项时，会在原题图上使用荧光、圈选或箭头；关键公式与推导由本机按真实文字行高顺序排版，不采用模型返回的坐标。长公式自动换行，剩余空间不足时自动新建续页，从而避免板书互相覆盖。随讲标记存于本机 IndexedDB，可撤销、重做和导出。
- 实时课堂左侧保留原题、函数图、运动图和板书页的缩略图历史。桌面端可纵向滚动，手机端可横向滚动并点击回看；手动选页会暂停自动跟随，避免老师的新页面抢走视图，点击“回到讲解页”才恢复。结构化画布事件必须先于对应 `say`，客户端在句子开始朗读时切换到讲解页。
- 可从系统提供的中文音色中选择声音，并调节 0.85–1.45 倍语速。应用会优先选择名称带 Natural / Online 的中文音色；实际自然度取决于电脑和浏览器已安装的语音，不等同于 ChatGPT 原生语音。
- 第一次进入课堂需要完成一次读图和区域定位，可能明显慢于后续问答；同一课堂的后续问答不会重复上传大图。

- 语音课堂默认用四至八个适合口头表达的句子回应；要求“完整讲解”时会完整分步讲，不受旧快速提示模板限制。
- 每节课堂默认最多 20 轮，可在 `.env` 用 `KIMI_VOICE_TURN_LIMIT` 设置为 3–50。
- 实测清晰数学题在一次读图准备后，后续完整讲解的首句约 1.55 秒可供朗读；这是本机当次测试结果，不是网络服务延迟保证。
- Kimi 当前公开 Chat Completions 接收文本、图片和视频，不接收本应用的原始麦克风音频。中文语音识别和声音输出由浏览器提供，不是 Kimi 原生实时音频流。
- 浏览器语音识别服务可能依照浏览器厂商政策处理麦克风音频；页面只将用户确认或主动开启自动提交后的转写文字发给 Kimi。结束课堂、切到后台或关闭页面会停止识别与朗读并重新屏蔽麦克风。
- 为减少扬声器回声误触发，应用在朗读结束后短暂冷却，并忽略紧随其后的最近朗读文本回声。

隐私与消费保护：

- 只有点击“讲这一题”并勾选本次确认后，当前画布 PNG 与问题才会经 `127.0.0.1` 本机代理发送到 Kimi API。
- 默认每个浏览器会话最多请求 5 次，可在 `.env` 通过 `KIMI_SESSION_LIMIT` 调整为 1–20。
- 图片分辨率会影响 Token 消耗；发送前可先裁剪题目范围。
- Kimi 返回的结构化批注建议默认不选中。必须由用户勾选并再次确认，应用才会添加；模型不能直接修改原画布。
- 本次未加入实时音频 API。讲解完成后可以使用浏览器的“本机朗读”，它不代表 Kimi 实时语音或远程控制。

互动辅导默认为“快速引导”：只返回一个下一步、短原因和一个检查问题；需要完整推导时再主动切换“详细讲解”。回答文字会从本机代理流式显示。可以框选题目区域后再问，也可开启“停笔 12 秒后提示”，但停笔功能只在本机显示询问按钮，绝不会自动调用 API。

### 安全云代理

项目所有者已授权部署安全云代理。云模式仍由同一个 Node 服务提供网页和 API，但增加强制启动门槛：Kimi Key、至少 24 字符的独立访问口令、至少 32 字符的 Cookie 签名密钥以及 HTTPS 源站缺一不可。未解锁的 AI API 返回 401；访问口令只用于换取短期 `HttpOnly; Secure; SameSite=Strict` Cookie，不保存在浏览器本地数据中。非同源 POST 被拒绝，登录失败按来源限速，Service Worker 不缓存任何 `/api/` 请求。

容器与 Render Blueprint 位于 `Dockerfile` 和 `render.yaml`，完整步骤见 `docs/CLOUD_DEPLOYMENT.md`。基础学习功能仍无需登录或云服务；题图只在用户主动讲题后转发，云端不持久化题图、录音、白板或学习记录。

备用文字模式中的麦克风仍作为浏览器语音转文字入口：点击开始/停止，或按住说话、松开结束；识别语言为中文 `zh-CN`。转写结果会先放入可编辑输入框，只有用户再次点击“讲这一题”时，最终文字才发送给 Kimi。原始麦克风音频不会由本应用发送给 Kimi；切换到后台会停止识别。不支持 Web Speech Recognition 的浏览器会保留完整键盘输入流程。

## 安装为应用（PWA）

网页版现在提供渐进式 Web App 清单和本机离线基础壳。首次正常打开后，可以从 Edge、Chrome、Android 或华为浏览器的菜单选择“安装应用/添加到主屏幕”；iPhone/iPad 使用 Safari 的“分享 → 添加到主屏幕”。安装后仍是同一套本地优先应用，基础计划、日报和已加载页面不需要 API Key；Kimi 讲题仍需要本机 Node 代理和网络。

- 当前正式运行地址仍是 `http://127.0.0.1:4174`，仅供同一台电脑访问，不会为了手机安装而自动开放局域网端口或上传用户数据。
- PWA 可作为 Windows/macOS/Linux 桌面应用窗口，也可在支持的手机浏览器中添加到主屏幕。iOS、华为和 Android 应用商店的原生签名包尚未发布；它们需要对应开发者账户、签名证书、商店审核和移动端安全代理设计，不能由 GitHub 登录权限替代。
- Service Worker 明确绕过 `/api/` 请求，不会缓存 Kimi 对话、密钥、题图请求或回答。

每次 Kimi 辅导分成两阶段：先用严格 JSON 返回“能力边界自检”和一次性本机凭证，通过能力门后才发起流式讲解，因此被拦截的题目不会提前生成答案。来源清晰度、难度、模型自评信心、图像依赖度和简短理由会直接显示。高信心时正常进入快速辅导；中等信心时先显示风险提示，由用户确认是否继续；低信心、来源不清或高度依赖图像时默认拦截解答，建议转到 ChatGPT 学习模式或上传截图给 GPT 复核。用户可以点击“仍要 Kimi 尝试”覆盖拦截。此分类只是 AI 自我检查，不是正确性保证；系统提示明确要求模型承认不确定、索要更清晰材料，并禁止虚构题干或推导。
